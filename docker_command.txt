
测试容器
/home/zxw 本机要挂载的文件
/workspace 虚拟机的挂载地址
docker run -it --rm -v /home/zxw:/workspace docker.m.daocloud.io/pytorch/pytorch:1.12.1-cuda11.3-cudnn8-runtime bash



创建容器
--name zxw_torch1.12 是容器名字
docker run -dit --name wyf_torch1.12 --gpus all   -v /home/zxw:/workspace   docker.m.daocloud.io/pytorch/pytorch:1.12.1-cuda11.3-cudnn8-runtime



进入运行中的容器
docker exec -it wyf_torch1.12  bash
docker exec -it wyf_vd_torch2.0.1 bash
docker exec -it wyf_vd_torch2.0.1-dev bash

查看容器状态
docker ps -a | grep zxw_torch1.12

停止容器
docker stop wyf_torch1.12

启动已停止的容器
docker start wyf_torch1.12

推出容器
exit
